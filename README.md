# AI Integrity Test: Fabricated Memory Recall

This repository hosts a static GitHub Pages site that analyzes integrity flaws in large language models based on a fabricated memory recall experiment. The site is built with Astro, TypeScript, Rust-WASM, and TailwindCSS, ensuring high performance, interactivity, and data immutability.

## Setup

1. Clone the repo.
2. Install Node LTS, Rust toolchain, and Python 3.12.
3. Run `pnpm install` for JS deps.
4. Run `cargo build` for Rust.
5. Run `pnpm run dev` for development.
6. Run `pnpm run build` for production build.
7. Deploy to GitHub Pages via CI or locally.
